## Instrument finding — the scoring instrument mis-measures implementing agents

Surfaced by the current run and carried here because it is a methodology defect, not a campaign
finding.

**Five of the seven dimensions (Specificity, Actionability, Substitution, Evidence, and much of
Coverage) measure the quality of an agent's *reporting*.** That is correct for a reviewer, whose
entire output *is* a report. It is wrong for an implementing agent, whose output is code and whose
report is commentary on it.

The PR #1094 implementing agent authored **13 optimistic safety-claim overclaims and 8 vacuous
tests** — every defect that nine review rounds found — and scored **5/5 on Specificity and 5/5 on
Evidence**, because it described each of those defects with exceptional precision, reproduced each
before fixing, and mutation-verified each fix afterward. Its total (27) landed **above** two
reviewers whose failures were far narrower. **The instrument pays for eloquent self-disclosure at
the same rate it pays for not having produced the defect.**

The disclosure is genuinely valuable — it is why this scorecard could reconstruct nine rounds at
all — and it should not be scored to zero. But it should not offset authorship either.

**Proposed amendment (A-3):** when the scored entity is an *implementing* agent rather than a
reviewer, add an eighth dimension — **Defect authorship**: the rate at which the agent introduced
defects that downstream review had to catch, scored inversely, with recurrence inside a prior fix
for the same class treated as the severe case. On PR #1094 that dimension scores **1**, and the
total falls to the range the narrative already argues for. Without it, every future
implementer-heavy campaign will produce the same mismatch between the number and the finding, and
future observers will resolve it the way I did — with a prose disclaimer, which is weaker than a
score.
